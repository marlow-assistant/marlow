# Memory files

One topic per file (`travel.md`, `work-projects.md`, `people.md`), each opening
with frontmatter like this file's. The `description:` is the one line you see
of the file on every turn, so make it say what the file holds *now*.

This directory starts empty apart from this file. It is yours to grow.
